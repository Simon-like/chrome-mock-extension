# Mock Studio 工作台原型评审

直接打开 `index.html`，或在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory docs/prototypes/workbench-ui-demo
```

然后访问 `http://127.0.0.1:4173/`。

## 三个方向

| 方向 | 性格 | 适合 |
| --- | --- | --- |
| A · Signal Blue | 精确、清晰、偏工程工具 | 状态区分最直接 |
| B · Circuit Teal | 平静、低刺激、稍有本地工具气质 | **默认**；适合长时间使用 |
| C · Slate Violet | 品牌感更强，保留蓝紫记忆 | 偏好更强品牌感时 |

三套方向使用完全相同的布局和内容，只替换 token，便于单独判断配色。

## 可交互内容

- 顶部切换管理工作台 / DevTools 与三套配色。
- 点击“空数据-无账户”打开不会被滚动容器截断的 viewport popover。
- 切换变体会更新当前态、播放一次 Trace Rail 状态动效并给出反馈。
- 展开“高级响应设置”查看渐进披露。
- 点击“保存更改”查看保存反馈。
- `Esc` 关闭菜单；系统设置减少动态效果时自动取消动画。

## 动效基线

| 动效 | 时长 | 意图 |
| --- | --- | --- |
| 变体菜单 | 140ms | 建立触发器与浮层的空间关系 |
| 页面切换 | 180ms | 避免内容瞬间跳变 |
| Inspector 进入 | 220ms | 表达它是当前选中规则的上下文面板 |
| Trace Rail 脉冲 | 420ms，一次 | 说明变体切换影响下一次结果，不循环吸引注意 |
| Toast | 180ms | 确认保存或切换完成 |
