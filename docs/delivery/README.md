# 交付记录与历史快照

这里保存某个日期的路线图、状态和交接上下文。快照不追改，因此只代表文件日期当天；判断当前实现必须同时检查代码、测试和新的状态记录。

| 日期 | 快照 | 用途 |
| --- | --- | --- |
| 2026-08-05 | [下阶段规划](./snapshots/2026-08-05-roadmap.md) | 当时的优先级和技术债；P0–P2 后续已完成 |
| 2026-08-07 | [项目状态与交接](./snapshots/2026-08-07-project-handoff.md) | 当时的功能盘点、架构速览、已知坑和遗留债务 |

一轮开发结束时新增 `YYYY-MM-DD-project-status.md`，不要覆盖旧快照。跨期仍有效的约束应提升到全局约束或 ADR，而不是只留在交接文档里。
